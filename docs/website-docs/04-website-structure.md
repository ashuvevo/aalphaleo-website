# 04 - Website Structure

> Website Documentation Library Aalphaleo Digital Solution

------------------------------------------------------------------------

# Purpose

This document defines the complete information architecture, navigation
hierarchy, URL conventions, and page relationships for the Aalphaleo
Digital Solution website.

The website is designed to maximize lead generation while establishing
authority in **Custom Shopify Website Development**.

------------------------------------------------------------------------

# Website Goals

-   Simple navigation
-   Fast access to services
-   Strong internal linking
-   SEO-friendly URL structure
-   Excellent user experience
-   High conversion rate

# URL Rules

-   Lowercase only
-   Hyphen-separated words
-   Short, descriptive slugs
-   No query parameters for content pages

Examples

/services/shopify-development/ /services/meta-ads-management/
/case-studies/

------------------------------------------------------------------------

# Page Hierarchy

Level 1 - Home

Level 2 - About - Services - Portfolio - Blog - Contact

Level 3 - Individual Service Pages - Individual Case Studies - Blog
Articles

------------------------------------------------------------------------

# Homepage Linking Strategy

Home should link directly to:

-   About
-   All primary services
-   Portfolio
-   Case Studies
-   Pricing
-   Blog
-   Contact

Every major section includes a CTA.

------------------------------------------------------------------------

# Service Page Linking

Each service page should include:

-   Related Services
-   Portfolio examples
-   Case Studies
-   FAQ
-   Contact CTA

Example:

Shopify Development → Shopify CRO → Shopify SEO → Meta Ads → Contact

------------------------------------------------------------------------

# Blog Linking Strategy

Every blog should link to:

-   Relevant service page
-   Related blog posts
-   Contact page
-   Portfolio where appropriate

# Internal Linking Rules

-   Minimum 5 internal links per service page.
-   Link related services together.
-   Link blogs to services.
-   Link portfolio to case studies.
-   Link footer to all important pages.
